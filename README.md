# 🃏 Зубрилка — тренажёр карточек из XML

Офлайн-тренажёр для зубрёжки чего угодно: вопросы с вариантами ответов,
картинками и звуком. Порции карточек, повторы ошибок, серии, подсказки,
пояснения и статистика. Без сборки, без зависимостей — чистые HTML/CSS/JS.
Все данные остаются в вашем браузере.

## Возможности

- **Библиотека колод** — готовые колоды из папки `decks/` (XML + медиа
  подгружаются автоматически), поиск, сортировка, кольцо прогресса по каждой колоде.
- **Тренировка** — порции (10/20/30/50/100/все), ошибочные карточки уходят
  на повтор, серия верных ответов, «Не знаю», подсказки, пояснения после ответа.
- **Множественный выбор** — у карточки может быть несколько правильных ответов.
- **Медиа** — картинки (клик → полноэкранный просмотр с зумом и переносом)
  и аудио (встроенный плеер) в вопросах и вариантах.
- **Конструктор** — сборка колоды мышкой: варианты, кружки правильных ответов,
  файлы, подсказки, пояснения, drag-сортировка карточек, автосохранение черновика.
- **Импорт** — перетащите `.xml` + медиа или целую папку; несколько XML
  сливаются в одну колоду, дубликаты пропускаются.
- **Экспорт** — XML, ZIP «XML + медиа», просмотр и копирование XML-кода.
- **Звук** — сигналы ответов и фанфары (WebAudio, без файлов), выключается одной кнопкой.
- **Хранение** — localStorage (прогресс, колоды, настройки) + IndexedDB (медиа).
  Можно отключить — тогда всё живёт до закрытия вкладки.

## Быстрый старт

Нужен любой статический HTTP-сервер (ES-модули и fetch не работают через `file://`):

```bash
# вариант 1 — Python
python -m http.server 8080

# вариант 2 — Node (скрипт в комплекте)
node tools/serve.mjs

# вариант 3 — что угодно ещё
npx serve .
